# 富士胶片色彩复现：资料整理与参数映射

> 目标：把"富士感"里最容易被说糊的两件事说清并落到参数上 —— **青绿色倾向**，以及**高光与暗部各自的性格**。
> 本文件是 `film-emulation-batch` 富士预设的设计依据。所有曲线、交叉量、颗粒值都由脚本直接算出，不是示意。
> 逐款的完整数值见 [preset-reference.md](preset-reference.md)；对应的曲线图与交叉矢量图见 [images/fuji-curves-and-crossover.png](../images/fuji-curves-and-crossover.png)。

---

## 一、先分清两家在哪个环节分岔

"柯达暖、富士冷"这句话太粗，真正决定观感的是三处，而且都能变成参数：

| 分岔点 | 富士 | 柯达 | 对应参数 |
|---|---|---|---|
| **绿色往哪偏** | 青绿 / teal / aqua | 黄橄榄 / yellow-olive | `hue_bands.green.hue`（正=青，负=黄） |
| **白点与高光** | 干净、不带黄，高光偏品红或中性 | 在真正 clip 之前就先转琥珀金 | `temp`、`crossover.highlight`、`sat_hi` |
| **反差曲线形状** | 更紧：高光更早到顶、暗部反差更大 | 更宽：高光肩部长、暗部有"体量" | `shoulder` / `shoulder_k` / `shadow_contrast` |

另外两条常被忽略但影响"像不像"：

- **黄被压**。富士对黄的克制是它的身份证（柯达相反，黄红都往上推）。→ `hue_bands.yellow.sat` 取负值。
- **边缘锐度（acutance）**。富士底片观感更"锐"，不是颗粒细，是边缘反差高。→ `acutance`。

## 二、逐款的性格与复现手段

### 负片系

**Fujicolor SUPERIA X-TRA 400** —— 富士负片的标杆
- 深阴影 + punchy 反差 + 极好的绿；高光带轻微品红，正是这个"品红高光"让画面有电影感而非糖水感
- 关键工程背景：**第四感光层（青/品红）**，本为压荧光灯绿偏，副作用是日光下绿色显得**更密、更冷**，粉色更亮
- 常用后期配方：白平衡 5000–5200K、绿 hue 往 aqua 推、黄 sat 下调 10–15、阴影略抬（负片不像反转片那样把黑压死）
- 复现：`temp -0.30`、`crossover.shadow` 青绿、`crossover.highlight` 品红、`hue_bands.green.hue +8`、`hue_bands.yellow.sat -0.18`、`shadow_contrast 0.20`、`toe 0.12`

**Fuji 經典 Neg.（Fujifilm 官方胶片模拟，基于 SUPERIA）** —— 与上面刻意区分开
- 官方描述是"高反差色阶；**通过改变明暗区色调、同时抑制饱和度来增加色彩深度**"
- 所以它不是"Superia 更浓"，而是**暗部更硬、高光转暖、饱和度反而更低**，靠色调分离而不是饱和度取胜
- 复现：`contrast 0.28` + `shadow_contrast 0.34`（暗部硬调）、`crossover.highlight` 转暖琥珀、`sat 0.90`

**Fuji C200** —— 廉价但不"黄"
- 柯达 Gold 用黄把画面泡起来，C200 选择"冷而准"，日光下更接近真实
- 复现：`temp -0.26`、`yellow.sat -0.15`、`green.hue +6`

**Fuji Pro 400H** —— 最值得单独讲的一款
- 第四层青/品红乳剂；官方数据书称其"在荧光灯与混合光下也能还原自然色彩，并因此带来前所未有的立体感"
- 日光下：**绿色更密更冷、粉色更亮**
- 性格核心是**高光极软**（压缩而非截断）和**暗部永不死黑**；专业摄影师的常规操作是**过曝一档**（按 ISO 200–250 拍）
- 后期配方：Highlights −25~−40、Shadows +15~+25、Blacks −5~−10、中间调锚点抬 3–5；Green Hue 往 aqua +8、Orange Hue 往黄 +3~+5、Magenta −3~−5
- 复现：`shoulder 0.55` + `shoulder_k 1.2`（滚降开始得很早、很柔）、`lift 0.022–0.026` + `toe 0.40`（永不真黑）、`shadow_contrast -0.08`、`exposure +0.10`、`sat 0.86`、`magenta.sat -0.08`、`orange.hue +4`

### 反转片系

**Fujichrome Velvia 50**
- 绿如**祖母绿**、极细颗粒、极高饱和与反差；蓝天深邃
- 缺点同样鲜明：**开敞阴影有明显品红 cast**；宽容度极窄，过曝半档高光就回不来
- 复现：`contrast 0.34`、`shoulder 0.90` + `shoulder_k 5.0`（晚而陡的滚降 → 容易爆）、`shadow_contrast 0.28` + `lift 0.003`（深黑）、`crossover.shadow` 品红、`green.sat +0.34`、`sat 1.20`、`grain 0.35`

**Fujichrome Provia 100F**
- 富士标准反转片，色彩最准、**略偏冷**；绿忠实，不往祖母绿跑；暗部保留比 Velvia 好得多
- 复现：`contrast 0.22`、`shadow_contrast 0.12`、`green.hue +3`（克制）、`blue.sat +0.10`

### 数码胶片模拟

**CLASSIC CHROME** —— 官方描述："低饱和度、**阴影中的硬色调过渡**，适合需要真实感的纪实摄影"
- 复现：`contrast 0.16` + `shadow_contrast 0.34`（反差全押在暗部）、`shoulder 0.68` + `k 2.4`（高光柔）、`sat 0.82`、`yellow.sat -0.18`、`crossover.shadow` 偏青蓝、高光冷静不转暖

**ETERNA** —— 官方描述："饱和度降至最低以避免任何色彩突出；**高光与暗部的柔和过渡可避免过曝与欠曝**"
- 复现：`contrast 0.06`、`shoulder 0.50` + `k 1.0`（极早极柔的双肩）、`shadow_contrast -0.10`、`lift 0.022`、`sat 0.78`

**ACROS 100**（黑白）
- 官方称"世界最佳颗粒性"：颗粒极细、暗部细节丰富、锐度高
- 复现：`mix [0.28, 0.64, 0.08]`、`grain 0.90 / size 0.80`（细而紧）、`acutance 0.20`（最高）、`tone` 略冷

> 顺带：富士还有一款 **Nostalgic Neg.**（高光琥珀、阴影蓝绿），性格与 Pro 400H / ETERNA 都不重叠，需要的话可以再加。

## 三、为复现富士，引擎新增了四个原语

原来的管线只有"每通道曲线 + 亮度插值色偏 + 饱和度分档"。这**做不出"绿色向青绿偏移"**——逐通道曲线无法改变色相。所以补了：

### 1. 色相带选择性调整 `hue_bands`
在 Rec.601 的 Y/Cb/Cr 对偶空间里操作。每个色带表示成 (Cb,Cr) 平面的**单位方向**，权重用**余弦相似度**得到（免 `atan2`、免三角函数），再按一阶近似做旋转：

```
angle = Σ radians(hue_b) · w_b
w_b   = clip((cosΔhue_b − cos(width)) / (1 − cos(width)), 0, 1)^power × chroma权重
Cb' = (Cb − angle·Cr) · gain ,  Cr' = (angle·Cb + Cr) · gain
```

角度约定经过实测校准：**颜色顺序 red 113° → orange 146° → yellow 173° → green 225° → cyan 293° → blue 353° → magenta 45°**，所以**正值 = 绿→青绿**，负值 = 绿→黄橄榄。

实测（对真实场景取样点）：
| 样本 | 原色相 | 富士 Superia 后 | Δ | 柯达 Gold 后 | Δ |
|---|---|---|---|---|---|
| 树叶绿 | 205.5° | 211.8° | **+6.3°** | 201.9° | −3.6° |
| 草地绿 | 193.2° | 198.3° | +5.2° | 191.5° | −1.7° |
| 琥珀黄 | 155.8° | 158.2° | +2.4° | 155.8° | 0.0° |

中性灰完全不受影响（靠 chroma 权重），空 `hue_bands` 往返误差严格为 0。

### 2. 暗部硬度 `curve.shadow_contrast`
只在暗部区生效的反差加权，正=压暗（富士的"暗部硬调"），负=提暗（Eterna / Pro 400H）。与 `toe` 是一对反向手段：`toe` 抬暗部软着陆，`shadow_contrast` 压暗部加密度。

### 3. 白平衡倾向 `temp` / `tint`
复现各家底片的白点差异 —— 富士整条线**偏冷（约 5000–5200K）**，柯达偏暖。这是"像不像"的第一道关，比任何曲线都先被人眼捕捉。

### 4. 边缘锐度 `acutance`
带 pad 边距的 FFT 反锐化掩模，避免分带接缝。富士预设 0.10–0.20，柯达 0.06–0.08 —— 这直接复现"富士观感更锐"。

## 四、高光与暗部的复现（用户重点）

| 现象 | 富士的做法 | 参数落点 |
|---|---|---|
| **高光偏品红**（Superia / C200） | R↑ B↑ G↓ 的高光交叉 | `crossover.highlight = [+0.014, −0.005, +0.011]` |
| **高光褪色更狠、白点干净** | 高光段饱和度大幅下调 | `sat_hi 0.86`（Superia）／`0.78`（Pro 400H） |
| **高光极软、不爆**（Pro 400H） | 滚降起点很早 + 滚降极柔 | `shoulder 0.55`、`shoulder_k 1.2` |
| **高光晚到顶、容易爆**（Velvia） | 滚降起点很晚 + 滚降很陡 | `shoulder 0.90`、`shoulder_k 5.0` |
| **高光冷静不转暖**（Classic Chrome） | 高光交叉略微偏蓝 | `crossover.highlight = [−0.004, +0.002, +0.004]` |
| **阴影偏青绿** | G↑ B↑ 的阴影交叉 | `crossover.shadow = [−0.006, +0.011, +0.016]` |
| **阴影深且有密度** | 暗部区加反差 | `shadow_contrast 0.20`（Superia）／`0.34`（經典 Neg. / Classic Chrome） |
| **阴影硬调** | 同上，但更早介入 | 配合 `shoulder` 一起缩放 |
| **负片不把黑压死** | 趾部软着陆 | `toe 0.12`（Superia）／`0.40`（Pro 400H） |
| **阴影永不真黑**（Pro 400H / Eterna） | 黑位大幅抬升 | `lift 0.022–0.026` + `toe 0.36–0.40` |
| **开敞阴影品红 cast**（Velvia） | 阴影交叉整体偏品红而非青绿 | `crossover.shadow = [+0.012, −0.006, +0.010]` |

对照图（[`images/fuji-curves-and-crossover.png`](../images/fuji-curves-and-crossover.png)）的**面板 ②** 把这件事一图说清：把每个预设的"阴影偏色"与"高光偏色"画成 (R−G, B−G) 平面上的箭头 ——
- **富士向左上走**：青绿阴影 → 品红高光
- **柯达向右下走**：琥珀阴影 → 暖金高光

这是两家色彩科学最本质的区别，也是"富士感"最该被抓住的一点。

## 六、已知局限（别把它当物理仿真）

1. **没有光谱感光曲线**。真实底片的青层/品红层响应是波长函数，这里只是显示空间的色彩交叉。做"风格复现"足够，做"某卷胶片在某种光源下的精确还原"不够。
2. **色相带是宽环带**，无法区分"花黄"与"土黄"，也无法对同一色带内的不同材质分别处理。
3. **颗粒是高斯噪声按亮度调制**，不是乳剂颗粒的团簇结构 —— 放大到 200% 看，缺那种"结块"的不规则感。`size` 只能调粗细。
4. **反转片的局部饱和度突变**（Velvia 对红/绿/蓝的强推）用宽环带近似，边缘会有轻微溢色。
5. **没做扫描仪的贡献**。真实"富士感"很大一部分来自扫描与校色环节（Pro 400H 就常因扫描不当留下绿或粉 cast），这里直接从 sRGB 数码原片出发。
