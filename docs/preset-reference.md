# 预设参数全表

17 款预设的每一项数值都是引擎里 `PRESETS` 的直接导出，不是示意值。改预设前先读 [README 的管线一节](../README.md#管线与校验)。

字段含义速查：

| 字段 | 含义 |
|---|---|
| `contrast` | 全曲线 S 形强度（0–0.4） |
| `shadow_contrast` | 暗部区反差加权，**正 = 压暗（暗部硬调）**，负 = 提暗 |
| `shoulder` / `shoulder_k` | 高光滚降起点 / 滚降陡度。起点越小越早压高光，`k` 越小越柔 |
| `toe` | 趾部软着陆（抬暗部），负片不把黑压死靠它 |
| `lift` | 黑位抬升（列 R 通道值），哑光黑 |
| `sat` / `sat_hi` / `sat_sh` | 中调 / 高光 / 暗部饱和度 |
| `temp` / `tint` | 白平衡倾向，`temp` 正 = 偏暖，`tint` 正 = 偏绿 |
| `hue_bands` | 色相带调整，`hue` 正数 = 向青/蓝方向旋转，`sat` 为该色带饱和度增益 |
| `grain` | `amount` 强度（1.0 ≈ 中调 σ4.9 灰阶）/ `size` 颗粒粗细(px) / `chroma` 色度颗粒占比 |
| `halation` | `amount@threshold`，阈值以 sRGB 等效值给出 |
| `acutance` | 边缘锐度（反锐化掩模强度） |
| `vignette` | 暗角强度 |
| `crossover` | `阴影向量 / 高光向量`，每通道加减量，单位 1.0 全幅 |

## 相对原图的改动量（实测）

对同一批 39 张 24MP 建筑照，`verify_batch.py` 抽样的平均 `|Δ|`：

| 预设 | 平均\|Δ\| (0–255) | 整体亮度变化 |
|---|---|---|
| `portra400` | 4.5 – 6.4 | −1 ～ −3 |
| `superia400` | 6.6 – 9.3 | −3 ～ −5 |

**经验阈值**：低于 4 基本看不出风格；6–9 是"有味道但不假"的区间；超过 10 要怀疑过调。

## CLI 参数

```
-i/--input      输入目录或文件（可多个）        -o/--output   输出目录
-p/--preset     预设名                        --group       fuji | kodak | all（一次跑完整个家族）
--pattern       文件名正则过滤                 --recursive   递归子目录
--limit         只处理前 N 张                  --suffix      输出文件名后缀（默认 _<preset>）
--quality       JPEG 质量（默认 96，4:4:4）    --format      jpg | png
--jobs          并行进程数（默认 min(6, CPU)）  --max-edge    限制长边像素（预览用）
--seed          颗粒种子（固定即复现）          --lut/--lut-strength   外部 .cube 3D LUT 与混合强度
--grain/--halation/--vignette/--sat/--contrast/--exposure/--temp/--tint/--acutance   单次覆盖预设值
--sheet         生成全预设对比图（传入一张源图）  --sheet-presets / --group   控制对比图包含哪些预设
--list          列出全部预设                   --dry-run     只列文件不处理
```

## 加一款自己的预设

在 `PRESETS` 里加一项，最少这五个字段就能跑；`hue_bands` / `crossover` / `acutance` / `halation` 可省略：

```python
"my_film": {
    "label": "My Film 400",
    "note": "一句话说明",
    "temp": -0.10, "tint": 0.0,
    "curve": {"contrast": 0.20, "shoulder": 0.80, "shoulder_k": 3.2,
              "shadow_contrast": 0.10, "toe": 0.15,
              "lift": [0.010, 0.011, 0.012], "gamma": [1.0, 1.0, 1.0]},
    "crossover": {"shadow": [-0.004, 0.008, 0.012], "highlight": [0.012, -0.002, 0.008]},
    "hue_bands": {"green": {"hue": 6, "sat": 0.10, "width": 50}},
    "sat": 0.98, "sat_hi": 0.90, "sat_sh": 0.98,
    "grain": {"amount": 1.0, "size": 1.0, "chroma": 0.25},
    "halation": {"amount": 0.25, "threshold": 0.86, "radius": 0.0055, "tint": [1.0, 0.60, 0.45]},
    "acutance": {"amount": 0.14, "radius": 1.0},
    "vignette": 0.10,
},
```

然后**必须**跑一遍 `scripts/verify/verify_crop.py` 做 1:1 验收，再看 `verify_batch.py` 的平均改动量。
