# 江南园林电影色：参考图复刻

## 风格锚点

参考来自一组古风园林与室内剧照。它包含两个由场景光源决定的分支，而非一张 LUT 能无差别套用的色相：

| 维度 | 冷调园林 `jiangnan_cool` | 暖光室内 `jiangnan_amber` |
|---|---|---|
| 白点与色调 | 整体微冷；暗部蓝青，植物灰青绿，石木可带灰紫 | 环境深褐黑，亮部保留奶油黄和烛火琥珀 |
| 影调 | 中高整体反差；暗部压深但留纹理；高光柔和，不做纯白大片 | 暗背景与局部暖光形成强明暗分离；亮部柔和 |
| 饱和度 | 全局低至中低；压黄绿、橙红，允许粉花/服装作为有限色彩重点 | 全局中低，局部灯火和肤色较暖；其余区域克制 |
| 质感 | 细颗粒、低锐化、轻微高光扩散和暗角 | 细颗粒、轻暖色光晕、轻暗角 |

这是对截图可见色彩的**视觉近似**，不是影片官方 LUT，也不是由原始摄影素材精确反推的曲线。拼图中的黑色分隔条和压缩噪声不应参与色彩判断。

## 选片判断

1. 参考图用于识别风格；实际调色应选未套色的相机 JPG、RAW 或普通照片。不要把参考拼图本身、已有预设输出或同一场景的重复帧当成独立成果。
2. 优先找园林植物、旧建筑瓦檐、木石质感、框景、明暗分离和少量亮部。冷调预设需要这些线索共同支撑。若原片是现代霓虹、鲜艳商品、证件照或纯白高调场景，应说明匹配度低。
3. 暖光预设只有在原片存在蜡烛、钨丝灯、室内暖窗光或夕照时使用。预设能强化已有光色，不能创造光源。
4. 人像须看肤色是否被推成绿灰；若出现，降低 `--tint` 或减小饱和度/对比度的改变量，必要时用局部蒙版处理。当前引擎只有全局调整，没有人物识别与局部蒙版，不能宣称已单独保护肤色。

## 执行顺序

1. 根据 SKILL.md 的源判定流程处理 RAW、Log 或普通成片；同名相机 JPG 和 RAW 只选一个版本来对比。
2. 先用 1200–1600 像素长边生成预览。选 `jiangnan_cool` 或 `jiangnan_amber`，再按原片光线微调 `--exposure`；不要用一种曝光值强行覆盖整批。
3. 复核植物是否灰青绿、亮部是否未变脏/过曝、阴影是否还看得见结构。若背景太黑，优先减弱 `--contrast` 或给少量正 `--exposure`；若太艳，微降 `--sat`；若偏绿，调低 `--tint`。调整后再全分辨率输出。
4. 并排对比必须使用同一张原片、同一裁切和尺寸，标明预设及任何覆盖参数；在 1:1 局部看颗粒、边缘和暗部，检查输出尺寸与 EXIF 方向。报告选片理由与主要变化，不把场景差异说成调色效果。

两个预设已写入 `scripts/film_emulate.py` 的 `PRESETS`，使用固定 `--seed` 可复现颗粒。示例：

```bash
python scripts/film_emulate.py -i "D:/photos/roof.jpg" -p jiangnan_cool -o "D:/out" --source auto --seed 20260926
python scripts/film_emulate.py -i "D:/photos/candle.jpg" -p jiangnan_amber -o "D:/out" --source auto --seed 20260926
```
